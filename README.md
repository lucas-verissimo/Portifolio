# Portfólio de Lucas Veríssimo

Portfólio profissional publicado em [lucas-verissimo.github.io/Portifolio](https://lucas-verissimo.github.io/Portifolio/).

A página foi refeita em HTML e CSS, com um pequeno script para o ano no rodapé. Não há build nem dependências de execução: o GitHub Pages serve os arquivos diretamente. Para conferir localmente, abra `index.html` em um servidor estático.

Os projetos destacados são Engenharia Clara, VideoDrop, Candeia e Prime House. A Engenharia Clara é uma demonstração autoral de uma empresa fictícia; o portfólio não atribui clientes ou resultados comerciais a ela.

`projetos.html` redireciona para a seção de projetos da página principal, preservando links antigos.
